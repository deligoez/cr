# cr v0.11.1 — What a full mutation pass found

> The release notes for the `v0.11.1` tag.

v0.11.1 is what a mutation pass over the whole of v0.11.0 left behind: one scanner fix, one
repaired script, and tests for every surviving mutant a test could see. The contract is still
`spec/0.11.0.md`; nothing cr reports changed except the one scanner case below.

## Install

```bash
brew install deligoez/tap/cr
go install github.com/deligoez/cr/cmd/cr@v0.11.1
```

## A Rust raw C string is read as raw

The symbol scanner read `cr"…"` — Rust's raw C string literal — as an identifier `cr` followed by an
ordinary string, so a backslash before a quote inside it was taken as an escape and the string ran
on past its end. A declaration after such a literal could then be missed or misplaced. The scanner
now treats the `c` prefix the way it already treated the `b` of a raw byte string.

## The mutation pass

gremlins ran over all 31 packages, one package per invocation: KILLED 4187, LIVED 208, NOT COVERED
962, TIMED OUT 61. `internal/cli` alone took 12 hours 46 minutes at two workers.

Every survivor was classified by applying its mutation by hand through `go test -overlay`, never on
disk:

- a survivor a test could observe got that test, which goes red under the mutation and green
  without it — 152 of the 208;
- the other 56, which nothing can observe, are recorded in `scripts/known-survivors.json` with the
  argument and the measurement that makes each one unobservable.

None of the survivors exposed a defect in the code as shipped. Several of the mutants crashed —
negative slice capacities in `cr next`, `cr brief` and the sandbox, a nil dereference when a
sandbox cannot be created — in input ranges no fixture had reached, and those ranges are now
covered.

## The mutation script is executable again

`scripts/mutation-run.sh` shipped in v0.11.0 without its executable bit, so running it exited 126.
The bit is restored, and a test now fails when any script under `scripts/` is not executable.
