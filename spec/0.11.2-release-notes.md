# cr v0.11.2 — One repository in every spelling

> The release notes for the `v0.11.2` tag.

v0.11.2 closes three small items the first real rounds and the v0.11.0 QA pass left in the roadmap.
The contract is still `spec/0.11.0.md`.

## Install

```bash
brew install deligoez/tap/cr
go install github.com/deligoez/cr/cmd/cr@v0.11.2
```

## A repository has one state directory

GitHub names a repository by every spelling of its slug, and cr named its state directory by the
spelling it was handed. `--repo Deligoez/CR-QA-GO` found a round opened as `deligoez/cr-qa-go` only
because macOS's filesystem folds case, so on a case-sensitive filesystem the same command found no
round; `--repo owner/repo.git` found none anywhere. Every `owner/repo` — from `--repo` or from the
clone's remote — is now folded to lower case and loses a `.git` suffix before it names a directory.

## `cr next` sends a missing intent cell through the intent pass

When a unit is missing its intent-coverage cell, the review step now opens with
`cr review <pr> --axis intent`, the intent pass's own emission, before the plain `cr review` that
hands every other role its prompts. The cell was always named; the command that fills it first was
not.

## The draft step asks for the bodies in the team's language

cr stores every record in English and renders a block's first body verbatim, so a draft whose
`render.lang` is Turkish holds English bodies under Turkish labels until the agent rewrites them.
The skill has always said so; the first real round was run by hand, never read that step, and
reached the reviewer in English. `cr next`'s draft step now says it: have the agent rewrite each
block's body in `render.lang` before the human reads the draft. With `render.lang: en` it says
nothing.

## Upgrading

Nothing to do for state cr wrote from a lower-case remote, which is every GitHub remote cr has
been measured against. State opened under a mixed-case `--repo` on a case-sensitive filesystem sits
in a directory the folded slug no longer names; rename it to lower case under `~/.cr/state/` and
`~/.cr/repos/`.
