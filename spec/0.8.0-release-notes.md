# cr v0.8.0 — Two more languages

Until now cr shipped profiles for a Laravel repository and a Go module only. On a
TypeScript or Rust pull request the test axis needed a hand-written runner, probes
had nowhere to place a test, and the reinvention search was off. v0.8 ships both.
The contract is [`spec/0.8.0.md`](0.8.0.md); only §2.4.5 changed.

## `typescript`

- Selected by `package.json`, `tsconfig.json`, `vite.config.ts` and
  `vite.config.js`, whichever are present.
- Runs the repository's own Vitest: `npx --no vitest run --reporter=verbose`.
  `--no` means nothing is ever installed; a repository without Vitest exits 1
  with no test line, and cr reads that as undetermined, not as zero tests.
- Counts one ` ✓ ` or ` × ` line per test. A skipped test is not counted. A
  suite whose import fails and a path that selects no file both exit 1 with no
  test line, and are undetermined.
- `--filter` becomes `-t`, `--path` is passed as Vitest's file filter, and a gap
  probe's test is placed beside its target as `cr_probe_<id>.test.ts`.
- Indexes `.ts`, `.tsx`, `.js`, `.jsx`, `.mjs`, `.cjs`, `.mts`, `.cts` and
  `.vue`: classes, interfaces and enums; `function` declarations; arrow
  functions bound by `const` or `let`; and methods, including a Vue component's
  options-API methods. A class's parameter count is its constructor's.

## `rust`

- Selected by `Cargo.toml` and `Cargo.lock`.
- Runs `cargo test --no-fail-fast`. Without the flag cargo stops at the first
  failing test binary and the counts cover only the ones before it.
- Counts `test … ... ok` and `... FAILED` lines, doc-tests included; an ignored
  test is not counted. A crate that does not build prints no test line and exits
  101, which is undetermined.
- `--filter` is passed after `--`, as libtest's name filter. `--path` is refused,
  because cargo selects a test target by name, not by file. A gap probe's test is
  an integration test, `tests/cr_probe_<id>.rs`.
- Indexes structs, enums, traits and unions, free functions, and methods. A
  method's `self` is its receiver and is not counted as a parameter, as Go's is
  not. A lifetime's quote (`&'a str`) opens no string, so the parameters and the
  body after it are still read.

## `go` names two markers

`go` is now selected by `go.mod` and `go.sum`. A Go module that carries a
`package.json` at its root selects `go` rather than tying with `typescript`. One
that also carries a `tsconfig.json` is a tie, which cr names; set `profile` in the
per-repository config. `cr init` updates an unedited `go.json` from an earlier
release and reports one it has not updated yet.

## Measured

- Every count is asserted against output captured from Vitest 5.0.1 and cargo
  1.98.1 on darwin/arm64 (`internal/profile/testdata/vitest` and
  `internal/profile/testdata/cargo`).
- The scanners were run over real code. On tarfin's Vue frontend: 1,737 files,
  7,130 declarations, 7,087 with a bounded body, and no control-flow word indexed
  as a declaration. On the 13,271 Rust files of a cargo registry: 254,228
  declarations, 252,268 with a bounded body.

## Known limits

- A React project whose runner is Jest selects `typescript`, and every run reads
  undetermined. Give it its own `tests.cmd`.
- The scanners read one line at a time. They miss a method or an arrow function
  whose parameters span lines, and a JavaScript `#private` method. A missed
  declaration is never replaced by an invented one.
