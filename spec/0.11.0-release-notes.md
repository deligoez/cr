# cr v0.11.0 — What the QA pass found

Three QA agents drove v0.8 through v0.10 against local Vue, React and Rust
repositories through a `gh` shim, against `deligoez/cr-qa` and
`deligoez/cr-qa-go`, and against adversarial inputs and real code (tarfin's Vue
frontend, a cargo registry). This release is what they found. The contract is
[`spec/0.11.0.md`](0.11.0.md); only §2.4 and §10.4 changed.

## The JavaScript profiles run their tests

- `typescript` and `jest` could not run a test in the sandbox at all. The
  sandbox is a fresh worktree, `node_modules` is ignored, and `npx --no` found
  no runner, so every `cr test` and every probe failed. Both profiles now copy
  `node_modules` into the sandbox, as `laravel-pest` copies `vendor`.
- A TypeScript project with a `jest.config.*` tied `typescript` and `jest` and
  was refused. A profile can now name files that take it out of automatic
  selection (`match.unless`, §2.4), and `typescript` names Jest's
  configuration files there.

`cr init` updates unedited `typescript.json` and `jest.json` files from v0.9.0
and v0.10.0.

## `cr recheck` reads GitHub

- It read the threads `cr brief` stored when the round opened, so straight
  after `cr post --confirm` it reported line 0, no replies and an unresolved
  thread while GitHub held the thread on its line. It now reads them live.
- It reports `start_line` and `original_start_line` beside the lines, as
  §9.5.2 requires.
- §9.5.4's re-run of a posted record's probe has never been implemented. A
  record naming a probe now says so in `honesty` instead of reading as though
  the probe had been looked at. ROADMAP carries the defect.

## A posted record keeps the kind it was posted as

A question the reviewer turned into a finding in the draft was posted as a
finding and stored as a question, so `cr verify … answered` accepted it. The
send now stores the register the author received.

## `cr next`

- A unit's first file with nothing owed ended the scan, so an empty file, a
  recorded one or a proposals file sorting first hid every role file after it,
  and their records were never merged. Every file is read now.
- Printed paths are quoted, so a command under a directory with a space in its
  name pastes as it should.
- An unreadable fan-out file is a file failure (exit 3), a directory is
  skipped, and a proposals file is matched by its whole name.
- A file mixing recorded and new ids is named, since `cr merge` refuses it.
- A profile file an earlier release shipped is reported, as §2.4.6 asks.
- A send whose outcome cr never learned owes `cr post --reconcile` and nothing
  else (§10.4.1). `cr next` used to offer `draft` or `brief`, which refused.

`cr recheck`'s refusal while a send is unresolved now gives its own reason; it
borrowed `cr draft`'s.

## The TypeScript and Rust scanners

- `#` opened a line comment in every language. A TypeScript private name or a
  Rust raw string then dropped the braces after it, and a body ran past the
  next declaration. It is a comment only in PHP now.
- An apostrophe in JSX text swallowed the next function. A TypeScript quote
  left open at the end of a line now closes there.
- Rust raw strings are read verbatim to their closing quote.
- A comma inside a generic type (`Map<string, number>`) counted as a
  parameter, and a Rust bound holding `-> ()` ended the generic list early.
  Either miscounted a parameter list and dropped a real reinvention candidate.
- `const ids = (items ?? []).map((i) => i.id)` is no longer indexed as a
  function, and `constructor(...) {}` on one line is.

On a cargo registry the scanner now bounds 253,926 of 254,228 bodies, up from
252,268.

## Smaller

- JSON output writes `<`, `>` and `&` as themselves, so a hint naming
  `<owner/repo>` reads as that.
- Refusing `--path` on a runner that cannot select by path now says to run
  without it, instead of telling a Rust user to declare a field cargo cannot use.
- `scripts/mutation-run.sh` cleans the test cache before every package, as
  CLAUDE.md requires; it cleaned it once, which lets later packages report a
  fake 100%.
- A test comparing the archived releases by name failed at the first two-digit
  minor version; it compares them as a set and holds the list to version order.
